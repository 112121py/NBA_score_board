# NBA Score & Betting Simulator

## Overview
This project provides a simple NBA game information and betting simulation system.  
Users can:
- Query NBA scores by date through a panel interface.
- Simulate betting with real-time odds retrieved from the web.

The project was developed as a **two-person collaboration**, aiming to integrate GUI design with web crawling techniques.

---

## Features
- **NBA Score Query**: Retrieve and display NBA game results by date.
- **Betting Simulator**: Simulate betting scenarios with odds collected online.
- **User Interface**: Built with JavaFX and SceneBuilder for an intuitive UI.
- **Web Crawling**: Implemented using Jsoup to fetch scores and odds data.

---

## Tech Stack
- **Frontend / UI**: JavaFX, SceneBuilder  
- **Web Crawling**: Jsoup  
- **Language**: Java
